# 솔레이스바디 (SolaceBody)

서울·인천·경기·부산 **동 1,232칸**과 지정 시군구 **152곳**에 출장마사지·홈타이를
방문하는 안내 사이트. 의존성 없는 Node 정적 생성기로 만든다.

```
npm run regions   # /tmp/hjd.geojson → data/regions.json  (좌표와 해의 자리 계산)
npm run build     # dist/ 생성
npm run check     # 빌드 결과 자체 검사 14종
npm run serve     # 로컬 미리보기
```

## 이 사이트가 쓰는 값 — 해의 자리

동마다 중심점 좌표를 NOAA 태양 위치 근사식에 넣어 **남중 시각**(해가 가장 높이
오르는 때), **하지·동지의 해돋이와 해넘이**, **낮의 길이**, 그리고 쪽을 낸 칸을
위도·경도로 줄 세운 **차례**를 계산한다. 날짜를 하지(6/21)·동지(12/21)·춘분(3/20)
셋으로 고정했으므로 몇 번을 다시 돌려도 값이 같다.

저녁과 새벽 방문에서 쓸모가 있다. 서쪽 칸은 같은 시각에도 아직 밝고, 해가 진
뒤의 골목에서는 번지가 보이지 않아 문 앞에서 시간이 샌다.

## 꼭 지키는 것

- **같은 주소 = 같은 HTML.** 무작위를 쓰지 않는다. 문장 고르기는 전부 md5 시드.
- **읍과 면은 쪽을 내지 않는다**(2026-10-13 지시). 시군구 쪽에 이름만 올린다.
- 전화번호는 `askBtn()` 안에서만 찍힌다. 버튼 라벨은 '예약 문의' 하나.
- 후기·체험담·평점·사람 사진 없음. 푸터에 AI 활용 고지.
- 설명문은 100자 안쪽. FAQ 질문은 `h3` 질문형(순번은 h3 밖).
- `data/lastmod.json` 을 **반드시 커밋한다.** 없으면 전 쪽이 매번 '오늘 수정'이 된다.

## 호스팅

Netlify. `netlify.toml` 과 `dist/_headers`·`dist/_redirects` 를 같이 둔다.
`_redirects` 의 느낌표는 Netlify 전용이라 기준 주소를 보고 붙일지 가린다(`src/build.mjs`).
